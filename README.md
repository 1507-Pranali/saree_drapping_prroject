Saree Draping Project

This is a web-based Saree Draping project developed using Python and Django.
The project provides a simple website related to saree draping and uses Django for the backend.

Technologies Used

Python

Django

HTML

CSS

SQLite

Project Structure

app/ - Django application files

media/ - Media files

saree_project/ - Main Django project

templates/ - HTML templates

db.sqlite3 - Database

manage.py - Django project management file

How to Run

1. Clone the repository

git clone <your-repository-link>
cd <project-folder>

2. Install Django

pip install django

3. Run the project

python manage.py runserver

4. Open in browser

Open the local URL shown in the terminal, usually:

http://127.0.0.1:8000/
